数据说明

数据来源：IMA 知识库（markdown 表格 → xlsx 中转）
同期口径：2025年1月1日-8月31日 vs 2026年1月1日-8月31日
过滤规则：状态为"已结束 + 待验收" + 报修科室编号非空 + 排除「培训/改装/升级/延保」+ 排除「设备移机/设备转运」+ 排除仓库类科室（会江总仓）
科室标准化：使用「报修科室名称映射表」（20260706 版，76 规范名/119 条映射）按统一名合并年度对比
响应/修复时长：仅保留正数（>0）；同一工单响应>修复时响应取修复值；分母为有有效时间的工单数
返修统计：排除以 YLSB 开头的资产编码；平均返修次数=排 YLSB 后维修≥2 次的资产平均维修次数
中心分类：5 大类（医疗 / 齿科 / 医美 / 眼科含视光 / 体检含健康管理）
设备分类：29 类 AI 三维分类体系 + 高价维修粗粒度设备类别（牙椅/医美/影像/灭菌/眼科/水处理/其他）
